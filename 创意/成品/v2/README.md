# 创意玩法知识网络 v2

当前最新小版本：`v2.8`。

v2.x 从 `创意/资料源/*_classified*.json` 全量重建，并经过三阶段去重合并与十二卷分类修正。

主要产物：

- `极品调教大世界书_v2.json`（即 `04_玩法世界书_v2.json`）：导入 SillyTavern 的主世界书。
- `极品调教快捷回复_v2_十二卷无状态版.json`（按钮名：`具体玩法`）：按「十二卷 + 特殊分类 → 子分类 → 分页条目」三级结构浏览具体玩法机制。
- `剧情片段/极品调教快捷回复_v2_剧情片段_整合版.json`（按钮名：`剧情玩法`）：按「小说类型 → 小说 → 剧情场景」浏览剧情玩法。
- `资料源索引_v2.json`：来源、分类、交叉索引和 UID 对照。
- `重建报告.md`：给人看的重建摘要。

公开仓库只保存发布产物和脱敏索引；本地资料源路径不写入发布版索引。
